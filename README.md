Root Companion est un mod Forge Minecraft 1.20.1 qui fait de Root un compagnon pour le joueur, utile et interactif. L’idée est simple : le joueur craft un objet `root`, le pose au sol, et obtient Root, la mascotte d'Aywen, qui suit son propriétaire et réagit à ce qu’il lui donne.

## Intégration de Root

Root n’est pas un simple ajout visuel : il est au cœur du gameplay. Le joueur interagit directement avec lui via le système de spawn, de nourriture et de buffs. Cette intégration rend Root essentiel à l’expérience du mod.

## Développement

Lancer le client de test :

```bash
./gradlew runClient
```

Construire le mod :

```bash
./gradlew build
```
